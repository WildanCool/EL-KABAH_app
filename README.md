## ✨ Fitur Utama
🕌 Jadwal Waktu Sholat
Menampilkan waktu sholat harian
Countdown menuju waktu sholat berikutnya
Tampilan modern dan elegan

🌍 Ubah Daerah / Kota
Mengganti kota untuk menyesuaikan jadwal sholat
Mendukung banyak kota dari berbagai negara

🧭 Arah Kiblat
Menampilkan arah kiblat secara akurat
Membantu pengguna menentukan arah sholat

📖 Al-Qur'an
Membaca Al-Qur'an langsung dari aplikasi
Tampilan nyaman untuk dibaca

🎥 Video Kajian Islami
Menampilkan video-video kajian dari YouTube
Kajian islami yang bermanfaat dan mudah diakses

📅 Jadwal Kajian
Informasi jadwal kajian islami
Membantu pengguna mengikuti kajian secara rutin

🤲 Dzikir & Doa
Kumpulan dzikir harian
Doa-doa yang bisa diamalkan sehari-hari

📱 Tampilan Aplikasi
UI modern
Tema islami elegan
Responsive design
Clean user interface

## 🚀 Cara Menjalankan Project
1. Clone Repository
git clone https://github.com/username/el_kabah_app.git

2. Masuk ke Folder Project
cd el_kabah_app

3. Install Dependencies
flutter pub get

4. Jalankan Aplikasi
flutter run

## 🎯 Tujuan Aplikasi
EL-KA'BAH APP dibuat untuk membantu umat muslim dalam:

menjaga sholat tepat waktu
membaca Al-Qur'an
mengamalkan dzikir dan doa
mengikuti kajian islami
mempermudah aktivitas ibadah sehari-hari
